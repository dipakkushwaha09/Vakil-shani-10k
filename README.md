## ✏️ रक़म या तारीख़ बदलनी हो तो

`script.js` में सबसे ऊपर ये लाइनें बदलें:

```js
var P=10000, MI=300, DI=10;      // मूलधन, महीने का ब्याज, रोज़ का ब्याज
var start=new Date(2026,10,6);   // साल, महीना (0 से शुरू: 10 = नवंबर), तारीख़
```

> रक़म बदलने पर `MI` (मूलधन का 3%) और `DI` (`MI` का 30वाँ हिस्सा) भी बदलें। `index.html` में दिखने वाला "₹10,000" और "₹300" टेक्स्ट भी बदलना होगा।
